## 🧋 Описание

Это демо-версия ERP системы для управления кофейней. Приложение представляет собой продолжение проекта, который был создан мной в
в рамках учебной дисциплины "Проектный семинар python в науке о данных". Предыдущая версия хранила данные в pickle и имела интерфейс, написанный на tkinter. 
Текущая версия использует PostgreSQL для хранения данных и интерфейс в streamlit. 

Система управления кофейней будет представлять собой полноценное приложение 
для управления ценами, меню и персоналом. В дальнейшем функционал приложения будет разделен в соответствии с ролями: бариста-кассир сможет принимать заказы, но не будет иметь
доступ к финансовым метрикам, в то же время менеджер сможет смотреть показатели продаж.

## 🔨 Стек

Python, PostgreSQL, streamlit, psycopg2, plotly

## 🔜 Скоро

Планируется реализация функций из описания, также возможно использование внутри приложения чата с llm или создание нейронных сетей для анализа трендов продажи создания рекомендаций

## Установка

Демо-версия доступна в streamlit community cloud

В дальнейшем возможно добавления способа установки через Docker.
